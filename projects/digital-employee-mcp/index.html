02

PROBLEM

项目背景：工具很多，但缺统一任务入口

工具能力分散时，员工仍需要理解不同入口、参数与调用方式，业务任务没有形成统一闭环。

项目从飞书统一聊天入口出发，让员工以自然任务描述发起工作，再由系统完成识别、路由、执行与结果回传。

03

PILOT

为什么先从运营岗位试点

运营岗位同时连接公司经营实绩、市场与竞品数据，任务频次高、判断链条长，适合验证真实业务价值。

  • 存在清晰且高频的经营诊断任务
  • 需要组合内部实绩与第三方市场估算
  • 结果可通过真实ASIN进行小范围验收

11

DATA TRUST

数据可信度与AI限制设计

AI可以分析，但不能把未知说成确定。

先明确数据来源、计算边界与缺失规则，再让AI参与综合判断。

  • 领星：公司经营实绩
  • 卖家精灵：第三方市场估算
  • Python：确定性计算
  • Missing ≠ 0
  • 缺失数据明确标记
  • 未取到的数据不虚构趋势
